# 西农课表转手机日历

把西北农林科技大学“我的课表 → 列表导出”的 `.xls` 转成通用 `.ics` 日历文件。提供 Windows 桌面界面和 Python 命令行版本。

文件在本机读取和转换。无需学校账号密码，不会自动登录学校系统，也不会上传课表。此项目为非官方工具。

## 使用步骤

1. 自行登录学校系统，进入“我的课表”，选择正确学期，点击 **列表导出**。不要选择“导出打印”。
2. 在 Windows 版本中双击 `NWAFU-Timetable.exe`，选择刚导出的 `.xls`。
3. 填写 **第 1 教学周的周一日期**。日期来自校历，不一定等于新生报到日或本人第一节课的日期。
4. 在“节次时间”中点击“填入冬季作息”或“夏季作息”，也可自行修改。两套时间抄录自 2026–2027 学年校历；校历未标明切换日期，请确认所选季节适用于导出的全部课程。
5. 可设置提前提醒分钟数、整天停课日期。在“季节切换”里可指定从某一天起采用冬季或夏季作息（包含当天）；不需要切换则留空。可保存学期设置供下次加载。
6. 点击“生成日期预览”，核对第一天、周末课、跨午休课程、日期和教室。勾选“已核对校历和节次时间”。
7. 点击“导出手机日历 .ics”。需要逐条核对时，可另行导出 CSV 核对清单。

## 安卓手机导入

- 将 `.ics` 文件通过 USB 或你自己的文件传输方式发送到手机。
- 在文件管理中打开，选择支持 ICS 的日历；也可查看日历设置中是否有“导入日程”。不同手机品牌、系统版本的入口不统一，部分系统日历没有直接导入功能。
- 若无法直接导入，可使用电脑端 Google 日历的 **设置 → 导入和导出** 导入，再在手机登录相同账号同步。此方法需要能访问 Google 服务，并会将课表保存到该账号。
- 建议导入到单独的“西农课表”日历。不同日历对重复导入的处理不同；更新时先清空或删除旧的专用课表日历，再导入新版，勿清空个人日历。
- 导入后核对一门普通课和一门周末课，确认通知权限。提醒是否生效还取决于手机通知和后台设置。

导入是一次性快照，不会自动同步退选、补选、调课和学校通知。ICS 中使用 UTC 时间戳记录北京时间对应的时刻；手机在其他时区时会按当地时间显示。

官方参考：[Google 日历导入说明](https://support.google.com/calendar/answer/37118?hl=zh-Hans)。

## 支持范围

- 支持原始 Excel 97–2003 `.xls` 列表导出文件；当前不支持 `.xlsx`、课表截图、打印版和其他学校的任意格式。
- 必要列：课程号、课程名、课序号、上课周次、上课星期、开始节次、结束节次、教室名称。
- 支持 `6-13周`、`12周`、`1,3,5周`、`1-16周(单)`、`2-16周(双)`，支持周次区间与单周数混合列表。
- 对无法识别、待定周次或缺失节次时间明确报错，避免静默漏课。空教室保留为空，可正常导出。
- 同课程、课序号、教室、日期的相邻小节合并；两节间隔超过 30 分钟则分段。合并后的提醒在该段第一节课之前触发。
- 完全重复的记录去重；不同课程的时间冲突在预览时提示，不擅自删课。
- GUI 支持第 1–12 节，命令行支持至第 24 节；周次支持 1–53。
- 支持按具体日期切换作息。界面支持一次冬季/夏季切换；命令行设置的 `clock_changes` 列表可设置多次切换，每项包含 `from` 日期与 `periods`。具体切换日期请按当年学校通知填写，不自动推算。
- 停课日期排除该日全部课程；不自动根据国家假期推断学校调课，不自动迁移补课。

## 源码运行

Python 3.10+，需带有 Tkinter（常见 Windows Python 安装包自带）。

```sh
python -m pip install -r requirements.txt
python app.py
```

命令行：复制 `settings.example.json`，填写日期与时间，然后运行：

```sh
python converter.py "导出数据.xls" --settings "我的学期设置.json" --output "西农课表.ics"
```
